# Hussain Web Solutions — Portfolio & Engineering Platform

Modern, high-performance portfolio for **M. Hussain** (Web Developer, Shopify & WordPress Developer, AI Automation Specialist).

## 🚀 Built With
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS + Custom Cosmic Design System
- **Icons:** Lucide React
- **Routing:** React Router 7 (Single Page Application with SPA Rewrites)
- **Deployment:** Vercel & Netlify ready (`vercel.json` and `netlify.toml` included)
- **Control Panel:** Hidden, authenticated `/admin` portal with live local sync

## 📦 Scripts
- `npm run dev` — Start Vite development server
- `npm run build` — Build production bundle to `dist/`
- `npm run lint` — Fast linting via Oxlint
- `npm run preview` — Locally preview production build

## 🌐 Deployment on Vercel
1. Import repository into Vercel.
2. Framework Preset: **Vite** (auto-detected).
3. Root Directory: `./` (or `hussain-web-solutions` if parent directory is imported).
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
